# خطة الإطلاق — SellerCtrl

**الهدف:** إطلاق تجاري لبائعي Amazon (ونون بعدها) على نظام بيقوم لوحده بعد أي عطل، بيانات كل شركة معزولة،
وحساباته ومخزونه متطابقين.
**قاعدة القرار:** مفيش إطلاق قبل ما كل بنود المرحلة 0 و1 تتقفل، والـrehearsal النهائي (المرحلة 6) ينجح.

**الرموز:** ✅ موجود — المطلوب تحقق وتوثيق بس · 🔧 محتاج شغل · 👤 مستني قرار أو بيانات من صاحب السيستم

> **حقيقة لازم تبقى قدامنا:** الإنتاج جهاز واحد (Docker على الجهاز ده + نفق Cloudflare). أي ريستارت أو
> انقطاع كهربا = السيستم واقع. يوم 2026-09-16 وقع ~9 ساعات لأن Docker ماقامش بعد الريستارت، ومحدش اتنبّه.
