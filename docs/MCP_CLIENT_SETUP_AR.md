# ربط حسابك بالتطبيقات بنفسك

افتح [روابط المساعد الشخصية](https://app.sellerctrl.com/settings/mcp) من حسابك في SellerCtrl. الصفحة تعرض الشركة الحالية وروابط هذا المستخدم فقط.

1. اختَر التطبيق من بطاقات الإعداد. انسخ عنوان الخادم أو إعدادات العميل المعروضة.
2. ابدأ الاتصال من التطبيق نفسه، ثم سجّل الدخول إلى SellerCtrl واختَر الشركة والصلاحيات ووافق. يجب اختيار OAuth مع التسجيل الديناميكي DCR عندما يعرض العميل خيارات التسجيل. لا يُستخدم مفتاح الشركة أو كلمة مرور ERP في ملف إعداد التطبيق.
3. ارجع إلى التطبيق وأرسل رسالة الاختبار المعروضة. حدّث حالة الروابط في الصفحة لمراجعة التفويض وآخر استخدام حقيقي. إنشاء طلب موافقة وحده يظهر «بانتظار إكمال الربط»، واستهلاك الرمز أو استخدام الاتصال يظهر «تم التفويض» ما دام التفويض غير ملغى أو منتهي. هذه حالة التفويض وليست ضماناً لبقاء التطبيق متصلاً بالإنترنت.

الإصدار الحالي للقراءة والتحليل فقط. كل تطبيق له تفويض مستقل لشركة واحدة، ومستخدم آخر لا يرى روابطك أو سجل طلباتك. تغيير الشركة أو الصلاحيات الممنوحة يتم بإلغاء التفويض وإعادة الموافقة، ولا يغير شركة تفويض قائم. إلغاء التفويض لا يحذف بيانات ERP.

يرجع اتصال الويب، مثل ChatGPT وClaude، إلى عنوان العميل المسجل في نفس تبويب/نافذة طلب التفويض للحفاظ على سياق OAuth لدى العميل. لا يفتح SellerCtrl نافذة إضافية له. نافذة التأكيد الصغيرة تخص عناوين الرجوع المحلية لبرامج الجهاز فقط. بعد تحديث هذا المسار، ابدأ محاولة جديدة من التطبيق؛ لا تُعد استخدام رابط موافقة أو رمز قديم.

نُشر تصحيح سياق الرجوع بالبناء `zjtjVf07LxbL2hVnAcB0i` بتاريخ 18 أكتوبر 2026. اختبار المتصفح كشف إنشاء نافذة ثانية في النسخة السابقة، ونجح بعد التعديل في الرجوع بالتبويب الأصلي والحفاظ على sessionStorage وstate وتبادل الرمز الحقيقي؛ يتجاهل الخادم أيضاً طلب popup_handoff المصطنع لعناوين الويب. نجحت فحوص المتصفح الثلاثون وأربعة اختبارات إعداد ومسارات، والبناء وTypeScript وESLint. يتطلب تأكيد حل رسالة ChatGPT لدى المستخدم محاولة فعلية جديدة من حسابه؛ لا يُعامل اختبار عميل ويب تجريبي كاختبار حساب ChatGPT.

## التطبيقات المشمولة

| التطبيق | طريقة الإعداد | المرجع |
| --- | --- | --- |
| ChatGPT | إضافة خادم MCP من Plugins، ثم OAuth وDCR | [OpenAI Docs](https://developers.openai.com/api/docs/guides/custom-mcp-server) |
| Claude | Customize ثم Connectors ثم إضافة موصل مخصص وRegister automatically | [Claude Help](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp) |
| Codex | أمر إضافة، أو أمر إعادة تفويض منفصل للخادم الموجود؛ لا يضاف oauth_resource يدويًا | [Codex MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) |
| Claude Code | إضافة خادم HTTP بنطاق المستخدم، ثم `/mcp` داخل العميل | [Claude Code](https://code.claude.com/docs/en/mcp) |
| Gemini CLI | إضافة خادم HTTP ثم `/mcp auth sellerctrl` داخل العميل | [Gemini CLI](https://geminicli.com/docs/tools/mcp-server/) |
| Cursor | ملف `.cursor/mcp.json` بمفتاح `mcpServers` ثم Authenticate | [Cursor MCP](https://cursor.com/docs/mcp) |
| VS Code / Copilot | MCP: Add Server ثم HTTP، أو ملف `.vscode/mcp.json` بمفتاح `servers` | [VS Code MCP](https://code.visualstudio.com/docs/agent-customization/mcp-servers) |

ملفات الإعداد القابلة للتنزيل تحتوي العنوان العام فقط، دون بيانات شركة أو مستخدم أو توكنات. تُدمج في ملف العميل الموجود ولا تستبدل خوادمه الأخرى. أوامر الطرفية المعروضة مناسبة لـPowerShell/Bash؛ أوامر `/mcp` تكتب داخل العميل كما توضح خطواته وليست أوامر Shell.

دعم Gemini هنا يخص Gemini CLI، ولا يُدَّعى أن واجهة Gemini العادية تقبل خوادم MCP مخصصة. كذلك لا تُعامل أسماء الموديلات كمفاتيح اتصال: التطبيق المضيف هو الذي يدير MCP، وقد يدعم اختيار موديلات مختلفة تحت نفس التفويض.

الخطوات راجعت الوثائق الرسمية بتاريخ 18 أكتوبر 2026. جرى التحقق من Codex فعلياً، ومن بروتوكول OAuth بعميل SDK الرسمي، ومن صفحة الإعداد بمتصفح تجريبي. لا يعني ذلك اختبار حساب فعلي داخل كل مزود؛ إتاحة الموصل المخصص تعتمد على نسخة العميل وصلاحيات المساحة وإعدادات المزود.

نُشرت صفحة الإعداد بتاريخ 18 أكتوبر 2026، بالبناء `O4VpHFhZCjC_0LbUwU11k`. نجح البناء وTypeScript، و11 اختباراً للإعدادات والترجمة، و36 فحص تكامل للعزل وOAuth، و26 فحص متصفح للموافقة والأدلة السبعة والنسخ وتنزيل إعدادات العملاء وRTL والموبايل، و4 فحوص حية لاستكمال تسجيل الدخول. التطبيق والعامل بنفس البناء وفحوص الصحة ناجحة. اختبارات إنشاء التفويضات جرت على قاعدة معزولة؛ لم تُغيّر مستندات ERP أو إعدادات مزامنة أمازون.
